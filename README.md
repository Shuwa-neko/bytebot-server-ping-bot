# ByteBot / ByteBot2E — Техническая документация и база знаний

**ByteBot (ByteBot2E)** — специализированный инструмент сетевой диагностики, сбора телеметрии и статистического анализа игровых серверов Minecraft (Java Edition).

Система работает как распределенный сканер: непрерывно опрашивает добавленные узлы, накапливает сырые временные ряды в базе данных и обрабатывает их методами математической статистики. Бот предназначен для владельцев проектов, технических администраторов и игроков, которым требуется не просто разовый статус «работает / лежит», а фактическая картина доступности, сетевых аномалий и распределения онлайна без учета искусственных накруток.
