# 📊 Команда `/bping` — Руководство по диагностике Minecraft Bedrock серверов

**`/bping`** — вспомогательный модуль сетевой диагностики **ByteBot (ByteBot2E)**, созданный по аналогии с базовым пингом, но предназначенный исключительно для опроса серверов **Minecraft: Bedrock Edition (PE / Win10)** по протоколу UDP.

## 1. Синтаксис и правила вызова

Базовый вызов команды:
```
/bping <домен> [порт]
```

*(Алиасы команды: `/bp`, `бпинг`)*

> [!TIP]
> **Быстрый вызов через Reply:** Вы можете использовать контекстный ответ на сообщение (Reply). Достаточно отправить команду `/bping` в ответ на сообщение с адресом Bedrock-сервера в чате, и бот автоматически извлечет домен.

---

## 2. Особенности работы с Bedrock-серверами

- **UDP-диагностика:** В отличие от Java-версии, работающей по TCP, пинг Bedrock-серверов отправляет специальный пакет с инкапсулированной клиентской мантией и `MAGIC`-байтами через протокол UDP (по умолчанию на стандартный порт `19132`).
- **Ограничение мониторинга:** Важно отметить, что **ByteBot не ведет постоянный фоновый мониторинг и статистику онлайна для Bedrock/PE серверов** — для этих задач поддерживается исключительно Java Edition. Команда `/bping` используется только для разовой ручной диагностики и проверки доступности карманных/консольных версий игры.

## 4. Разбор полей ответа (Структура карточки)

- **Информация о сервере:**
  - **Адрес:** Домен узла и текущий статус (`В сети`).
  - **Онлайн:** Текущее количество игроков относительно максимального лимита.
  - **Версия и Протокол:** Распознанная версия билда Bedrock и цифровой номер сетевого протокола.
- **Сеть и маршрутизация:**
  - **Прямой IP:** Рабочий айпи и UDP-порт сервера.
  - **Пинг (RTT):** Время отклика в миллисекундах (`ms`).
  - **Размер ответа:** Размер входящего пакета от сервера в байтах.
  - **Локация:** Страна хостинга и провайдер (ASN, включая узлы защиты вроде TCPShield).
- **Описание (MOTD):** Внутриигровой статус сервера, очищенный от лишних цветовых кодов.

## 5. Интерактивные кнопки управления

Под карточкой ответа доступны быстрые инструменты диагностики:
- **🌐 DNS:** Глубокая проверка DNS-записей домена (`/dns`).
- **📡 Query:** Запрос внутренней Query-статистики (если активирована на сервере).
- **🔍 Whois / 📑 RDAP:** Юридическая информация о хостинге и сетях.
